ARCHITECTURE
================================================================================

INGESTION PIPELINE:
  S3 Upload → EventBridge → Step Functions → Indexer Lambda → OpenSearch
  Bedrock Knowledge Base (async) → S3 → Chunk + Embed → OpenSearch

SEARCH/RETRIEVAL PIPELINE:
  Client → API Gateway → Search Lambda → OpenSearch → RAG Lambda → Bedrock
                      ↓
                  Suggestions Lambda → OpenSearch
